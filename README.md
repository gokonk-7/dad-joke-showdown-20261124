One dad joke, at most 200 characters, written to be told out loud — the whole
entry for make.fun's "Dad Joke Showdown" bounty ($5). A judge model reads
entries two at a time and picks the one that lands the bigger groan.

## The joke

> I told my kids I wanted to be a grape farmer. They said, 'Dad, you're already a raisin.'

88 characters. The turn is *raisin* / *raising*: a dad who has spent years
raising kids is already a raisin. Setup, straight face, punchline at the end —
and the grape-farmer angle keeps it off the well-worn joke circuit.

## Run it

```sh
node main.ts
```

Writes the joke to `/output/entry.txt` (UTF-8, 1–200 characters). Node 22.18+
runs `main.ts` directly; no dependencies, no network, no secrets.
